Sauvegarde et restauration

Enregistrer une copie de tes données

Crée un fichier JSON contenant les données Doméo enregistrées dans ce navigateur : clients, intervenantes, planning, factures, paiements et relances. Conserve-le dans un endroit privé et sûr.

Les données restent sur cet appareil tant que tu ne télécharges pas de sauvegarde. Aucune transmission vers un serveur.

Restaurer une sauvegarde

Attention : la restauration remplace les données Doméo présentes dans ce navigateur. Fais d'abord une sauvegarde de tes données actuelles.

Le contrôle compare le fichier et les données de ce navigateur sans rien modifier.

Après restauration, l'application se recharge automatiquement. Les fichiers de sauvegarde contiennent potentiellement des données personnelles : ne les partage pas publiquement.
